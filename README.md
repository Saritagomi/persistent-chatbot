# @saritagomi/persistent-chatbot

Drop-in AI chat widget that:

- **Survives page refresh** — history restored from local storage.
- **Renders markdown** — lists, tables, code blocks, safely (no `innerHTML`).
- **Streams tokens** — words appear as they are generated.
- **Keeps API keys on the server** — built-in backend handler.

Zero dependencies. Under 12 KB gzip.
